Qwen3.6-35B-A3B finetunes: fidelity of eklow's quantization mixes and of bartowski's / the official GGUFs
against each model's own Q8_0, as KL divergence of the next-token distribution (raw results; worker
qwen/weights, 2026-10-31 .. 2026-11-01, e-desktop).

Tool: llama-perplexity --kl-divergence at the revision flake.nix pins (llama.cpp ea0c4c2c), CUDA build
(tools/weights/cuda.nix) on the RTX 4090, layers that do not fit on the card left to the CPU (--fit on).
Base logits: the model's own Q8_0 (convert_hf_to_gguf.py --outtype bf16, then llama-quantize ... Q8_0), saved
once per text. Command (tools/weights/kl.sh, which holds the 4090 lock):
  llama-perplexity -m FILE -f TEXT -c CTX --chunks N --fit on --kl-divergence --kl-divergence-base BASE
Texts:
  wiki4k: wikitext-2-raw test, context 4,096, 20 chunks
  doc32k: one Pile document (son-of-anton:/work/data/compare/doc-131072.txt), context 32,768, 2 chunks
"PPL" is the file's perplexity on the text, "base PPL" the Q8_0's. Small differences between PPL and base PPL
in either direction are noise from the finite text; the KL columns are the measure. "same top p" is the share
of positions where the file and the Q8_0 pick the same top token. The raw llama-perplexity output of every
row is in ~/eklow-qwen-data/logs/kl/MODEL-TEXT-FILE.log on e-desktop (not committed: 2.5 MB).

Mixes (tools/weights/make-gguf.sh; the importance matrix is bartowski's, pinned, for the Q4_0/Q4_K/IQ4_XS
tensors; MTP/NextN block 40 left out with the converter's --no-mtp, llama.cpp loads the files):
  name  routed experts (ffn_{gate,up,down}_exps)  dense matrices (GDN attn_qkv/attn_gate/ssm_out, attention
                                                   attn_q/attn_output, shared expert)
  EK8   Q4_0                                       Q8_0     (what eklow's kernels read today)
